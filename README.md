# Junteng Liu — Homepage

Personal academic homepage of **Junteng Liu**, a first-year PhD candidate in the HKUST NLP Group at the Hong Kong University of Science and Technology (HKUST). He graduated from Shanghai Jiao Tong University (SJTU) in June 2024. His research focuses on natural language processing and machine learning.

## Repository structure

- `_pages/about.md` — home / about page (profile, education, research experience, publications, skills, awards, contact)
- `_pages/publications.html` — publications listing page
- `_publications/` — individual publication entries
- `_pages/cv.md` — CV page
- `_config.yml` — site-wide configuration and sidebar author profile
